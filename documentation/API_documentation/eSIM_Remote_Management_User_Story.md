## ***Summary***
Connected vehicles, power grid IoT terminals, smart wearables, mobile phones and tablets for outbound travel bring massive demands for flexible remote eSIM profile management. Manual replacement of physical SIM cards leads to high on-site operation costs and poor user roaming experience for cross-region/cross-border equipment. The eSIM Remote Management API suite provides five matching core interfaces for enterprise developers: profileDownload for remote profile distribution, profileEnable, profileDisable and profileDelete for enabling, disabling or deleting target profiles, and profileResultQuery for checking execution status of asynchronous remote tasks.

The full business closed-loop logic: enterprise developers initiate remote profile issuance tasks through profileDownload when needing new operator network resources; adjust profile working status through profileEnable, profileDisable or profileDelete; verify task execution results with profileResultQuery. The whole workflow completes full remote lifecycle management of eUICC profiles without hardware SIM replacement. The API suite is exposed to external parties through operator Open Gateway/NaaS platform, built based on GSMA standard SM-DP+ and terminal LPA SDK capabilities, and has stable commercial value in automotive IoT, power communication and overseas consumer terminal roaming scenarios.
## ***Scenarios - Management Scenario 1***
**Operators:**
Telecom operators expose the full set of eSIM Remote Management APIs through CU Open Gateway and dedicated eSIM remote management platform, providing enterprise customers full-lifecycle remote control capabilities for terminal eSIM profiles, supporting dynamic scheduling of multi-operator and cross-regional profiles to cut enterprise terminal operation and maintenance costs.
**API Consumers:**
Vertical industry enterprise developers. Eg: Automaker enterprise business platform
Auto manufacturers pre-purchase multi-region operator profile resources and synchronize vehicle EID & IMEI device data to operator eSIM management platform. When vehicles travel cross-region or cross-border, the vehicle enterprise backend calls the matching APIs in sequence to download local operator profiles, switch active network profiles and verify task execution results, realizing automatic regional network switching without manual on-site operation.
## ***Scenarios - Management Scenario 2***
**Operators:**
Telecom operators integrate eSIM Remote Management APIs on NaaS/Aggregator Platform, opening standardized eSIM remote management capabilities to external enterprise developer clients.
**API Consumers:**
Consumer device & IoT platform developers. Eg: Smart wearable brand developer, power grid IoT monitoring platform developer
**API End Users:**
Individual outbound travelers, remote power grid monitoring terminals
1. For outbound travel individual users: eSIM-equipped mobile phones, watches and tablets support users to purchase overseas roaming packages via brand official APPs; the APP backend calls the eRM APIs to remotely download local operator profiles, activate network services and query task results, enabling low-cost local network access without physical SIM card replacement.
2. For power grid communication terminals: Power IoT operation platforms download regional operator profiles according to local signal coverage conditions through profileDownload, switch active profiles via profileEnable and profileDisable, and query remote task execution results to ensure stable network transmission of power monitoring equipment in different geographic areas.
